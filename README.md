# Conservation Quiz App (2026)

A website to practice **Conservation Geography** (Primary) and **Conservation Economics** (Secondary) - 2026.

## Features
- **Two Complete Subjects:**
  - **Conservation Geography** (Primary Subject): 130 questions across Weeks 0 to 12.
  - **Conservation Economics** (Secondary Subject): 120 questions across Weeks 1 to 12.
- Fully interactive flashcard quiz engine with week-level filtering.
- Supports randomization of questions and multiple-choice options dynamically per user.
- Dark mode compatibility for late-night studying.
- Fast, resilient Single Page Application statically powered by React, TypeScript, and Vite.
- Automatically stores settings (like timer options and theme) via IndexedDB so preferences aren't lost on refresh.
